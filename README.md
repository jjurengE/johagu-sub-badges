# 조하구 2티어 움직이는 구독뱃지

치지직 조하구 채널 2티어 구독뱃지(1~54개월) 13종을 움직이는 버전으로 만든 작업물.

## 폴더

| 폴더 | 내용 |
|---|---|
| `apng/` | **치지직 업로드용** 72×72 APNG 13개 |
| `preview/` | 4배 확대 미리보기 GIF |
| `originals/` | 원본 정적 뱃지 (72×72 PNG) |
| `candidates/` | 2개월 후보 4종 (껌 풍선 / 축하 꽃가루 / 뿅망치 / 전구) |
| `src/` | 생성 스크립트 |
| `preview.html` | 13개 한눈에 보기 (움직이는 버전 · 원본 · 채팅창 크기) |

## 만드는 방식

원본마다 도트 한 칸 크기가 다르다 (1~12개월·54개월: 4px, 18~48개월: 3px).
각 뱃지를 "도트 한 칸 = 1픽셀"인 작은 그림으로 줄인 상태에서 움직이고 마지막에 원래 배율로 키워서,
모든 움직임·이펙트가 원본 도트 격자에 맞게 나온다.

```
pip install pillow
python src/animate2.py          # 13개 전부 다시 생성
python src/animate2.py 02 48    # 일부만
```

## 업로드 메모

- 치지직 일반 이모티콘 칸은 APNG가 막혔다는 커뮤니티 제보가 있지만(2026.3), 구독 뱃지는 APNG가 들어간다는 보고가 있음. 공식 문서는 확인하지 못함.
- 하나씩 올리고 저장하기. 스튜디오에선 움직이는데 채팅창에서 멈추면 해상도를 살짝 바꿔 재업로드.
- 안드로이드에선 첫 프레임에 멈춰 보일 수 있음 → 모든 뱃지의 첫 프레임은 원본과 거의 같게 맞춰 둠.
